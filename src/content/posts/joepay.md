## **一、能干什么**

- **付费下载**：百度网盘 / 天翼云盘 / 阿里云盘等资源的加密分享。访客付费、输卡密或填提取码后，才能拿到下载地址和提取码。
- **付费阅读**：文章里某一段内容付费解锁，支付后写入浏览器解锁状态，刷新不丢。
- **邮件自动发货**：下单后自动把下载链接、提取码、访问密码发到买家邮箱。
- **后台订单管理**：谁买了、买了什么、付没付款，一目了然。
- **买家自助**：凭邮箱查询自己的订单、一键重发已购商品信息，不用每次找站长。
- **风格统一**：可挂成主题的独立页面，长相和你的站点完全一致。

---

## **二、三种获取方式**

同一篇付费资源，可以任选其一或组合：


| **方式** | **说明** |
| -------- | -------------------------- |
| **密码下载** | 资源本身设了访问密码，访客付费后展示密码即可下载 |
| **在线支付** | 接入易支付 / 码支付，扫码付款后自动发货 |
| **卡密兑换** | 不接支付也能跑——你提前生成一批卡密，买家输入即解锁 |


> 小提示：就算不配置任何支付接口，卡密模式也能直接赚钱；等跑通了再接易支付也不迟。

## **三、安装与启用**

1. 把插件解压到 `usr/plugins/JoePay/`（目录名必须保持 `JoePay`）。
2. 后台「插件」列表中启用 **JoePay**。
3. 点「设置」填写两项关键配置：
  - **SMTP**：发信用的邮箱（QQ 邮箱用 `smtp.qq.com` + 465 + SSL + 授权码）。
  - **易支付 / 码支付**：接口地址、商户 ID、商户密钥（可不填，用卡密模式）。
4. 设置页里点「发送测试邮件到我的邮箱」确认 SMTP 通不通。

启用后，后台左侧会出现 **「JoePay → 订单管理」** 菜单。

> 如果你用的是本站同款 Joe 主题（自用修改版），主题已经内置了同款订单中心，**不装插件也有完整功能**；同时启用时主题会自动让位，由插件接管，不会重复渲染。两边读写的是同一张订单表，历史订单不用迁移。

## **五、后台订单管理**

进入「JoePay → 订单管理」，你能看到：

- 顶部 **6 张统计卡**：总订单数、今日新增、待付款、已成交、累计收入（¥）、退款/作废。
- **多维筛选**：状态、类型、关键字（订单号 / 邮箱 / 交易号 / IP / 卡密）、日期区间、文章 CID、买家邮箱精确查询。
- 点订单号展开完整字段（令牌、卡密、有效期等）。
- **单条 / 批量操作**：标记已付、完成、重置待付、退款、作废、删除。
- **CSV 导出**：按当前筛选条件导出，方便对账。
- 结果提示：成功 / 部分跳过 / 失败，一目了然。

> 退款或作废时，插件会同步吊销该订单的下载令牌，不会出现「退了钱还能继续下载」的漏洞。

## **六、买家自助：邮箱查询与重发**

很多站长最头疼的就是「我买过的东西在哪」「帮我再发一次」。JoePay 把这件事交给买家自己搞定：

1. 买家在 `/joepay/orders`（或你建好的独立页面）填入**下单邮箱**。
2. 系统发一封确认信（**不管这个邮箱有没有订单都发同一封**，防止被人拿来猜谁买过东西）。
3. 买家点信里的链接，验证后 24 小时内免重复验证。
4. 看到自己名下全部**已成交**订单，可单条或「全部重发到我的邮箱」。

安全细节：确认链接 15 分钟有效、一次性、HMAC 签名防篡改；同邮箱 10 分钟最多 3 次确认信、5 次重发；前台列表不暴露 IP 和完整订单号。

> 重发会让旧下载链接**立即失效**并重签新链接（不重置已下载次数）；发信失败会自动回滚令牌，不会出现「信没到、旧链接先废了」。

付费阅读的解锁状态存在浏览器本地，邮件里只列购买事实并提示回原文，无法靠邮件远程恢复——这点请提前告知买家。

## **七、做成站点风格的独立页面**

不想让买家跳到插件自带的裸页？两步就行：

1. 后台「管理 → 独立页面 → 新建」，右侧**自定义模板选「JoePay 订单查询」**，标题随意（比如「订单查询」），发布。
2. 把页面网址放进导航或页脚，这就是买家的统一入口。

该页面完整复用主题的头部、侧栏、页脚和配色变量，亮色 / 暗色自动跟随，长相和你的站点一模一样，且不会加载评论区。

## **八、安全说明**

- 订单数据落在 `{prefix}joe_download` 表，插件与主题共用，不新建分叉表。
- 邮箱验证、下载令牌、卡密核销均有防重放与限流；所有写操作带 Typecho Security Token + 管理员权限校验。
- 后台退款/作废会吊销下载令牌；支付回调已做签名与状态白名单校验。
- 所有面向用户的输出均做了 HTML 转义，防 XSS。
